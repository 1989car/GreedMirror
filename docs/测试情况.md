## 2. 静态检查

- 全部源码通过 Lua 语法编译（lupa Lua 5.5 `load`）；代码本身保持 WoW 客户端兼容的 Lua 5.1 子集语法。
- 打包产物校验：`dist/GreedMirror.zip` 内含 `GreedMirror/GreedMirror.toc` 及 10 个 Lua 文件，TOC 声明 `## Interface: 16001`、`## AllowLoadGameType: camelot`、`## SavedVariables: GreedMirrorDB`，加载顺序与文件一一对应。

## 3. 未能覆盖的部分（需游戏内验证）

离线桩无法替代真实客户端的以下行为，建议安装后用 `/greed probe` 与 `/greed self` 快速验证：

1. **三个统计 ID 的真实语义**（1044/1043/932 的名称校验结果）——`/greed probe` 会打印每个 ID 的原始值、解析值与名称；如官方调整了编号，插件会尝试按名称自动发现。
2. **服务端限频表现**：真实服务器对比较请求限频时的超时/重试节奏（离线用固定超时模拟）。
3. **现代设置页 API 在无限服客户端的实际可用性**（三级降级路径已实现：Settings API → InterfaceOptions → `/greed settings` 自绘面板）。
4. **提示框挂钩方式**：客户端无 TooltipDataProcessor，主路径为 GameTooltip OnTooltipSetUnit 脚本，退路为 UPDATE_MOUSEOVER_UNIT 事件。
5. **.savedvariables 持久化**（名单跨会话保留）依赖客户端 SavedVariables 写盘时机，离线无法验证。

## 4. 已知设计取舍

- 判为“低”（放弃型）的玩家不显示需求率、不追加提示行（按 design.md 第 36 行）。
- 高需求率名单的判定门槛为 P ≥ 50%（design.md 第 59 行），且仅统计通过活跃度门槛的玩家。
- 团队（40 人）不做自动扫描，只做名单提醒检查；小队只扫 party1-4。
- 本插件只读官方成就统计接口（SetAchievementComparisonUnit 链路），不调用 NotifyInspect / InspectAchievements，不注册受限事件，不写聊天频道。
