# 贪婪镜（GreedMirror）

魔兽世界插件：显示其他玩家的战利品需求率统计（需求 / 贪婪 / 掷骰 / 进本次数）。

适用版本：**魔兽世界：无限**（Interface 16001）。纯本地插件：**不联网、不上传、不向任何聊天频道广播**。

## ⚠️ 使用风险提示（请先阅读）

2026-11-14 起，国服官方已封禁同类"需求率统计"插件（NinjaWatcher 等），官方口径为"维护游戏环境"，继续使用者将被封号 3 天，屡次违规延长。

本插件只做与官方成就面板统计页完全相同的**只读展示**（不评价、不标记、不黑名单、不上传、不广播），但**使用此类插件存在账号处罚风险，请自行判断并承担**。关闭方式：游戏内"设置 → 插件 → 贪婪镜 → 启用插件"取消勾选。

## 安装

1. 解压 `GreedMirror.zip`，得到 `GreedMirror` 文件夹（内含 `GreedMirror.toc`）。
2. 放入客户端插件目录：`<客户端目录>/Interface/AddOns/`（部分客户端可能使用 `_retail_/Interface/AddOns/` 等子目录，以实际 AddOns 目录为准）。
3. 重新登录游戏，角色选择界面左下"插件"中应出现"贪婪镜"。

## 功能

- **鼠标提示**：指向玩家时，在提示框底部追加统计（如"贪婪镜 60% · 极高"）。任一数字读不到 → 显示"数据不可读"，绝不以 0 冒充；数据不完整时给出原因与建议。
- **手动查询**：`/greed self` 查自己，`/greed target [名字]` 查目标或指定队友。
- **队伍扫描**：`/greed party` 依次查询 5 人小队成员（团队不做自动扫描）。
- **高需求率名单**：需求率 ≥ 50%（已过活跃度门槛）的玩家自动记录（跨会话保留）。再次在队伍中遇到时，聊天框与屏幕中央各输出一条**仅自己可见**的提示（同一玩家 10 分钟内不重复提醒）。
- **缓存**：每位玩家独立缓存，档位为 实时 / 15 / 30 / 60 分钟（默认 60 分钟），到期后在下次查看时才刷新，无后台定时扫描。缓存重载 / 重新登录后清空。
- **阵营过滤**：只对同阵营玩家生效，敌方阵营玩家不查询、不显示、不记录。
- **兼容性**：针对"无限（camelot）"客户端做了事件注册容错、热加载兜底、提示框多级挂载（TooltipDataProcessor → OnTooltipSetUnit → 轮询看门狗）等适配。

## 设置

游戏内"设置 → 插件 → 贪婪镜"，含两个子页面：

- **常用**：启用插件 / 鼠标提示框显示 / 显示自身数据 / 详细次数 / 队伍高需求率提示（5 个开关）、查询间隔（四档循环）、清除缓存、清空名单（二次确认）。
- **名单**：高需求率名单列表（滚轮翻页），可一键清空。

所有设置改动立即自动保存。若客户端没有新版设置页 API，自动退回旧版插件设置面板；最差情况可用 `/greed settings` 打开。

## 命令一览

| 命令 | 作用 |
|------|------|
| `/greed` 或 `/贪婪镜` | 帮助 |
| `/greed self` | 查询自己的统计 |
| `/greed target [名字]` | 查询当前目标或指定队友 |
| `/greed party` | 扫描 5 人小队 |
| `/greed watch` / `watch clear` | 查看 / 清空高需求率名单 |
| `/greed probe` | 自检（客户端版本、接口可用性、统计 ID 校验、阵营判定） |
| `/greed settings` | 打开设置页 |
| `/greed cache` | 清空缓存 |

## 常见问题

- **显示"查询超时（服务端限频）"**：服务器限制了比较请求频率，稍后再试；插件已内置最小查询间隔与队列。
- **显示"数据不可读"**：该玩家的统计至少一项未上报或不可读，不是 0。
- **ID 校验异常**：官方调整统计项编号时，`/greed probe` 会显示校验结果，插件会尝试按名称自动发现正确 ID；发现失败则显示"数据不可读"。
- **成就窗口闪一下**：查询借用官方"成就比较"链路，结束后自动隐藏被顶出的成就窗口。
